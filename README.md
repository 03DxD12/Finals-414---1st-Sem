# Windows Server Administration - Exam Reviewer & Practice Suite

An interactive web-based study and review application for Windows Server Administration (Finals 414 - 1st Semester).

## Overview

This repository hosts an interactive single-page study application (`index.html`) covering core Windows Server topics, key administrative commands, diagnostic workflows, and self-assessment questions.

### Key Topics Covered

- **Active Directory Domain Services (AD DS)**: Domains, Domain Controllers, Organizational Units (OUs), Security Groups, and User Management.
- **Windows Server Update Services (WSUS)**: Update synchronization, staged deployment, computer groups, and client-side targeting.
- **File Server Resource Manager (FSRM)**: Hard vs. soft quotas, directory and volume quotas, quota templates, and file screening.
- **Shadow Copies & Server Backup**: Snapshot management, file-level vs. full system state backups, and disaster recovery testing.
- **Group Policy Objects (GPOs)**: Folder redirection, drive mapping, logon policies, security filtering, and troubleshooting (`gpupdate`, `gpresult`).
- **Security Policies & Auditing**: Account lockout mechanisms, System Access Control Lists (SACLs), and Event Viewer IDs (4624, 4625, 4720).
- **Active Directory Troubleshooting & Recovery**: DNS diagnostics (`nslookup`), replication checks (`repadmin`, `dcdiag`), RPC error 1722 resolution, FSMO roles (transfer vs. seizure), and Directory Services Restore Mode (DSRM).

## Application Features

- **Module Breakdown**: Comprehensive reference materials organized by topic.
- **Quick Cheat Sheet**: High-yield comparisons and essential administration commands.
- **Flashcard Mode**: Interactive cards for memorizing definitions and procedures.
- **Practice Exam**: Assessment engine with instant scoring and feedback.

## Getting Started

1. Clone or download this repository.
2. Open `index.html` in any modern web browser.
3. No build tools or local servers required.
